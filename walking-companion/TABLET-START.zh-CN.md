# 悠米一号横屏平板体验

网页与素材运行在平板浏览器。电脑和 Mosaico 连接同一手机热点，电脑运行随包附带的局域网服务，平板用打印出的地址打开网页。配对沿用 Mosaico 屏幕的当次六位码。

1. 在 Mosaico 打开「控制 → 手机 → 开启遥控」，记下显示的地址和六位码。
2. 在同一热点的电脑解压平板包，在包目录运行 `python -B start-tablet.py`。输入 Mosaico 的完整地址。
3. 看到 `UNION: http://…:8768/` 后，将这个地址输入平板浏览器。点击「立即体验」，选场景，点击「体验」并配对。语音与晃动场景的实际操作提示显示在按钮下方。
4. 回到 Mosaico 双眼首页。核对左右侧表情、语音文字和调用节点。点开开发者模式可进入手动控制。

直接回车启动同电脑预览。旧设备可以配对并使用原有场景命令，网页显示「已连接 · 表情预览」。现场实时表情和对话需要设备固件提供 `workbench` 回包。

## 验收记录

- 横屏 Chromium 1024×768、1234×678。模拟配对后核对邀请、语音文字、表情节点定位、三路输出高亮、开发者入口及返回首页。
- Anatomy 深浅版均通过 110 个实体的几何审计。布线为功能示意，三路接线按设备手册映射。
- 固件协议主机回归通过。独立候选基于 1.44.0 提交 `48ee43d`，固定 ESP-IDF 的 S31 构建通过。补丁也通过 1.46.0 主线工作副本的应用检查。现场固件整合、安装和物理平板热点联测待验。
