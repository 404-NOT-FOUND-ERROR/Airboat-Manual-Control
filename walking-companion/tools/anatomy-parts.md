# Mosaico 托架与外设

等轴测托架示意，沿用 110 个实体。托架正面按投影蚀刻部件名。场景演示开始时，视图聚焦对应部件并沿定位点显示功能标注。Mosaico 回报推进或俯仰动作时，视图优先展示该支路。装配位置为展示布局，接口和电源分支取自项目接线记录。

- 台架与支撑：底板、四只脚、两根托条、四个紧固头。
- Mosaico：壳体、边框、AMOLED、两眼及瞳孔、H1 连接座、H2 连接座、麦克风孔和扬声器格栅。
- H2 相机：载板、镜座、镜筒、镜片、排线座。
- H1 驱动：两块载板、两只芯片、四排端子、三组电机托、紧固件、三组外壳、三只轴套、三套桨叶和轴端。D1 A 路接转向桨 M1，D1 B 路接升降桨 M2，D2 A 路接前后桨 M3。设备上报非零输出时点亮对应支路并标注驱动输出百分比。
- 动力电源：1S 电芯、接头、两条固定带。主机与动力共地。
- I²C 扩展：PCA9685 载板、芯片、供电座、PWM 座、SG90 外壳、转盘、舵臂；BMP581 载板、金属封装、进气孔。
- 姿态取样来自 Mosaico 板载 BMI270。BMP581 已有读数，定高另验。活动头控制与自动飞控采用项目记录的互斥设计。

参考 Anatomy 的 Desk Computer 与 Dial Indicator。构建脚本用真实形状登记四面阴影、圆柱、轴套及投影层次。走线标出功能连接，实物脚序以接线卡为准。
